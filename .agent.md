# Agent: Vendor Management Assistant

## Purpose
This agent is designed to assist with managing vendor-related functionality in the MERN application. It focuses on enabling vendors to add and update their venue details, upload verification documents, and manage images for their gallery. Additionally, it supports the admin's role in approving or rejecting vendors.

## Features
1. **Vendor Functionality**:
   - Vendors can add and update venue details.
   - Vendors can upload verification documents.
   - Vendors can upload images, which are displayed on the gallery page.

2. **Admin Functionality**:
   - Admins can view and approve or reject vendors.
   - Vendors are listed as "unapproved" in the UI until approved by an admin.
   - Once approved, vendors are marked as "approved" and displayed accordingly.

## Tools and Preferences
- **Preferred Tools**:
  - File editing tools for modifying backend and frontend code.
  - Task management tools for tracking progress.
  - Python or Node.js tools for backend logic.
  - Browser tools for testing UI changes.

- **Avoided Tools**:
  - Tools unrelated to the MERN stack.

## Example Prompts
- "Add functionality for vendors to upload verification documents."
- "Create an admin dashboard to approve or reject vendors."
- "Update the gallery page to display vendor images."
- "List unapproved vendors in the UI with a distinct label."

## Customization Suggestions
- Extend the agent to handle notifications for vendors upon approval or rejection.
- Add analytics for admins to track vendor activity.
- Enable bulk approval/rejection of vendors by admins.

## Notes
This agent is tailored for the vendor management workflow in the MERN application. It ensures a clear separation of roles between vendors and admins while maintaining a user-friendly interface for both parties.
